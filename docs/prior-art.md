# Prior art and benchmark notes

Agent Radius intentionally starts with structural, evidence-backed analysis. Related areas include dependency analysis, software composition analysis, data lineage, impact analysis, and AI-agent policy systems. Before adding a feature that overlaps a known tool, record the tool, source URL, overlap, and the distinct Agent Radius behavior here.

Benchmark cases should contain:

- an initial repository snapshot;
- an agent action or Git diff;
- expected impacted entities and paths;
- actual output;
- precision, recall, path accuracy, and explanation coverage.

The heuristic score is a prioritization signal. It is not a probability and must not be marketed as one.
